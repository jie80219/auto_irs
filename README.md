# auto_irs — 高鐵半自動訂票

程式會幫你填好訂票表單，你只要輸入驗證碼，後面的選車次、填身分資料、確認訂位都由程式完成。

## 流程

1. `.env` 只放身分證字號：取票人 `THSR_ID`、TGo 會員 `THSR_MEMBER_ID`（可留空）
2. 執行後自動開啟本機介面 http://127.0.0.1:8000 ，在網頁上選起訖站、日期、出發時間區間、車廂、座位偏好、各票種張數
3. 按「開始訂票」，程式在背景開啟高鐵訂票網站並填好條件
4. **驗證碼圖片會顯示在介面上（同時跳 macOS 通知），由你輸入後送出**
5. 之後全自動：選時間區間內最早出發的車次 → 填取票人、會員、優待票乘客身分證 → 同意條款 → 完成訂位
6. 介面顯示訂位代號、座位、票價、付款期限與「訂位明細」截圖；截圖存到 `tickets/<日期>-<訂位代號>.png`，紀錄寫入 `bookings.log`

驗證碼錯誤、區間內沒有車次或頁面逾時會自動重來一輪（每輪都要再輸入一次驗證碼），可在「進階設定」調整重試輪數與間隔，也可以設定開賣時間讓程式準時開始。

> 驗證碼一定要由本人輸入。依《鐵路法》第 65 條第 2 項，以不正指令輸入電腦取得訂票最高可處 5 年有期徒刑，所以本專案不會加入自動辨識驗證碼的功能。

## 安裝

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/playwright install chromium
cp .env.example .env   # 填入身分證字號
```

## 使用

```bash
.venv/bin/python -m auto_irs            # 啟動介面並自動開啟瀏覽器
.venv/bin/python -m auto_irs --port 8080 --no-open
```

進階設定裡的選項：
- **測試模式**：跑到「完成訂位」前一步就停下，不會真的訂票
- **顯示高鐵瀏覽器視窗**：預設在背景執行；勾選後可以看到程式操作高鐵網站。某一步出錯時，視窗會保留讓你手動完成

上次填的行程會記在 `last_trip.json`，下次打開介面自動帶入。

## 網站改版時

所有頁面選擇器都集中在 `auto_irs/page_selectors.py`。任何一步找不到欄位時，程式會存截圖到 `screenshots/`、發通知，並保留瀏覽器讓你手動完成，再依截圖修改選擇器即可。
